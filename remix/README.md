# Remix generator: slowed + pitched down + reverb + bass boost

`remix.py` превращает трек в ремикс того же типа, что и `edited.mp3` относительно `orig.mp3`.

## Установка и запуск

```bash
pip install -r requirements.txt
python remix.py input.mp3 output.mp3                 # настройки как в образце
python remix.py input.mp3 output.mp3 --speed 0.9 --semitones -2 --reverb-mix 0.25
python remix.py --help                               # все параметры
```

Поддерживаются mp3, wav, flac, ogg (чтение и запись).

## Что отличает ремикс от оригинала

Измерено сравнением двух файлов (темп — по периоду ударных, тон — по совпадению
спектральных пиков и корреляции спектров, остальное — по разнице с оригиналом,
приведённым к тому же темпу и тону).

| Параметр | Оригинал | Ремикс | Параметр программы |
|---|---|---|---|
| Темп | ≈139 BPM (такт 1.73 с) | ≈117 BPM (такт 2.055 с), ×0.842 | `--speed 0.842` |
| Высота тона | — | −5.67 полутона (частоты ×0.72) | `--semitones -5.67` |
| Суб-бас ниже ~45 Гц | есть | срезан | `--highpass 50` |
| Бас 40–130 Гц | — | +10…13 дБ | `--bass 15 --bass-freq 110` |
| Середина 180–1000 Гц | — | +5…6 дБ (общая громкость) | `--loudness` |
| Верх 1.4–4 кГц | — | +11…13 дБ | `--presence 6.5` |
| Выше 11 кГц | пусто после сдвига тона | заполнено | `--air 8`, `--drive 3` |
| Реверберация | сухой звук, чёткие паузы | паузы заполнены хвостом | `--reverb-mix 0.4 --reverb-size 0.8` |
| Стерео на верхах (side/mid) | −20 дБ | −8 дБ (шире) | `--reverb-width 0.4` |
| Стерео на басу | моно | моно | `--mono-below 250` |
| Динамика (разброс уровня 5–95 %) | 18 дБ | 8 дБ | `--comp-threshold -28 --comp-ratio 4` |
| Громкость | −19.9 LUFS, пик −6.6 дБ | −13.1 LUFS, пик −3.5 дБ | `--loudness -13.8 --ceiling -3.5` |

Темп и тон изменены независимо друг от друга: простое замедление «как на пластинке»
до ×0.842 дало бы только −3 полутона. Новых инструментов в ремиксе не обнаружено,
порядок фрагментов тот же.

## Цепочка обработки

1. Растяжение по времени и сдвиг тона (Rubber Band через `pedalboard`).
2. Эквалайзер: крутой срез суб-баса, подъём баса, подъём верхней середины и «воздуха».
3. Мягкое насыщение (tanh).
4. Реверберация параллельно сухому сигналу, низ хвоста сведён в моно.
5. Компрессор, приведение к целевой громкости, лимитер пиков.

Любой этап отключается: `--drive 0`, `--reverb-mix 0`, `--highpass 0`,
`--speed 1 --semitones 0`, нулевые усиления эквалайзера.
